# AASM v0.25.0 — Generic Observability

v0.25 makes the formal calculus, decision backends, assurance layer, and package evolution inspectable through domain-neutral machine projections.

## Delivered

- Decision Graph projection;
- Obligation Graph projection;
- Evidence Graph projection;
- conflict and backjump timeline;
- event-derived restart, profile, candidate, and assurance timeline;
- fairness-debt view;
- package binding and migration history;
- candidate backend summary;
- assurance summary;
- generic `inspect_machine()` runtime surface;
- CLI inspection surfaces;
- v0.25 HTTP runtime wiring;
- observability schema and tests.

The built-in views describe AASM objects rather than assuming source code, CAD, science, business operations, or any other domain.
