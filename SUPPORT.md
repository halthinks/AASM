# Support

AASM is an early-stage open-source project maintained on a best-effort basis.

## Where to ask

- **Bug:** use the Bug Report issue template.
- **Feature or integration idea:** use the Feature Request template.
- **Documentation problem:** use the Documentation issue template.
- **Security vulnerability:** follow `SECURITY.md` and do not open a public vulnerability report.

When asking for help, include your Python version, operating system, installation method, relevant code, and the full error output when available.

Commercial support and response-time guarantees are not currently offered.
